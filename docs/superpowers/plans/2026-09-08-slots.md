# Slots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A five-reel, nine-payline slot machine that pays from a player-funded bank, so that no spin can ever mint a chip.

**Architecture:** A new `games/slots` workspace holding the reel strip, paylines and paytable as pure functions with no I/O, so the entire economy is testable as arithmetic. The machine is deliberately *not* a `PlayTable` and has no `GameAdapter` — it is one socket action (`slots:spin`) against a shared bank held in the economy store. The web client draws the cabinet and treats a spinning reel exactly as Blackjack treats a face-down card: motion starts on the press, symbols arrive only from the server.

**Tech Stack:** TypeScript, npm workspaces, vitest, Express + Socket.IO, React, Mongoose. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-08-slots-design.md`

## Global Constraints

- The strip is exactly **32 stops**: chip 9, dice 7, spade 6, horseshoe 4, bell 3, seven 3.
- Paytable multipliers are on the **line bet**, and the line bet is `stake / 9`.
- Every payout is `Math.floor((multiplier * stake) / 9)` — integers only, floor always.
- **Line RTP is 0.8999724686145782.** Any change to a weight or multiplier must retune to this.
- **The jackpot pays once per spin**, `Math.floor(bank * 0.4)`, however many paylines read five sevens.
- **`maxStake = Math.floor(bank / 1295)`.** Never a different divisor.
- The stake enters the bank **before** the reels resolve; wins leave the bank.
- Nothing but `POST /api/admin/bank` may add to the bank from outside play.
- No new npm dependencies.
- `npm test`, `npm run typecheck` and `npm run lint` must all be clean at every commit.
- Format only touched files: `npx biome format --write <paths>`. **Never** `biome check --write` across the repo — it applies an import-ordering assist this project deliberately leaves off.
- Check a stylesheet is imported before adding to it (`grep` for the filename first).
- Every keyframe needs a `prefers-reduced-motion` off switch.
- Check every screen at 375px wide before calling it done.
- Test files are **not** typechecked (`exclude: ["src/**/*.test.ts"]`), so a type error in a test will not fail `npm run typecheck`.
- DOM tests need `// @vitest-environment jsdom` as the first line of the file.

```ts
import { drawGrid, STOPS, STRIP, SYMBOLS, WEIGHTS } from "./strip.js";

describe("the strip", () => {
  it("is exactly 32 stops", () => {
    /*
     * Load-bearing. Every probability in this game is a weight over 32, and
     * the closed-form RTP divides by it. A strip that is 31 or 33 stops long
     * does not fail loudly — it quietly makes every other number here wrong.
     */
    const total = SYMBOLS.reduce((sum, symbol) => sum + WEIGHTS[symbol], 0);
    expect(total).toBe(STOPS);
    expect(STRIP).toHaveLength(STOPS);
  });

  it("puts each symbol on the strip as many times as it is weighted", () => {
    for (const symbol of SYMBOLS) {
      expect(STRIP.filter((stop) => stop === symbol)).toHaveLength(WEIGHTS[symbol]);
    }
  });

  it("draws five columns of three", () => {
    const grid = drawGrid(() => 0);
    expect(grid).toHaveLength(5);
    for (const column of grid) {
      expect(column).toHaveLength(3);
    }
  });

  it("reads three consecutive stops, so a column is a window on the strip", () => {
    // Not three independent draws: a reel is a loop of symbols and the rows
    // above and below the payline are its neighbours. Drawing them separately
    // would make every near miss a lie.
    const grid = drawGrid(() => 0);
    expect(grid[0]).toEqual([STRIP[0], STRIP[1], STRIP[2]]);
  });

  it("wraps round the end of the strip rather than running off it", () => {
    // Stop 31 is the last, and the two below it are the first two again.
    const grid = drawGrid(() => 31 / 32);
    expect(grid[0]).toEqual([STRIP[31], STRIP[0], STRIP[1]]);
  });
});
```

- [ ] **Step 4: Write the strip**

`games/slots/src/strip.ts`:

```ts
/**
 * What is painted on the reels.
 *
 * One strip, shared by all five reels. Five different strips is what a real
 * machine does and it buys nothing here: the arithmetic stays exact and the
 * tuning stays legible with one, and every extra strip is another set of
 * weights somebody has to keep in step with the paytable.
 */

export type Symbol = "chip" | "dice" | "spade" | "horseshoe" | "bell" | "seven";

/** The whole loop, and the denominator of every probability in this game. */
export const STOPS = 32;

/** Commonest first, which is also cheapest first. */
export const SYMBOLS: readonly Symbol[] = [
  "chip",
  "dice",
  "spade",
  "horseshoe",
  "bell",
  "seven",
];

/**
 * How many of the 32 stops each symbol holds.
 *
 * These are tuned against the paytable to land the return at 90%. Moving one
 * without retuning the other breaks that, which is why a test asserts the
 * return rather than trusting this table.
 */
export const WEIGHTS: Record<Symbol, number> = {
  chip: 9,
  dice: 7,
  spade: 6,
  horseshoe: 4,
  bell: 3,
  seven: 3,
};

/** The stops laid out in order, so a reel can be read as a window on it. */
export const STRIP: readonly Symbol[] = SYMBOLS.flatMap((symbol) =>
  Array.from({ length: WEIGHTS[symbol] }, () => symbol),
);

/**
 * Five columns of three, each a window of three consecutive stops.
 *
 * Consecutive rather than three independent draws, because the rows above and
 * below the payline are the reel's neighbours and a near miss has to be a real
 * one. Drawing them separately would show a player a row of sevens that was
 * never on the reel.
 */
export function drawGrid(random: () => number): Symbol[][] {
  return Array.from({ length: 5 }, () => {
    const at = Math.floor(random() * STOPS) % STOPS;
    return [0, 1, 2].map((offset) => STRIP[(at + offset) % STOPS] as Symbol);
  });
}
```

```ts
 * be argued with in a test file.
 */
```

```ts
import type { Symbol } from "./strip.js";

/**
 * The nine lines a spin is read along.
 *
 * Nine rather than twenty because a payline nobody can trace is not a feature.
 * At 375px each of these can be drawn across the glass and followed by eye,
 * which is the whole reason a payline is better than a count of matches.
 *
 * Each entry is one row index per reel, top row 0. The middle line comes
 * first because it is the one people look at, and a player reading "line 1"
 * off the screen should find it where they expect.
 */
export const PAYLINES: readonly (readonly number[])[] = [
  [1, 1, 1, 1, 1], // the middle
  [0, 0, 0, 0, 0], // the top
  [2, 2, 2, 2, 2], // the bottom
  [0, 1, 2, 1, 0], // the V
  [2, 1, 0, 1, 2], // the peak
  [0, 0, 1, 2, 2], // falling
  [2, 2, 1, 0, 0], // rising
  [1, 0, 0, 0, 1], // the arch
  [1, 2, 2, 2, 1], // the trough
];

export const LINE_COUNT = PAYLINES.length;

/**
 * What is on this line, and how far it runs unbroken from the left.
 *
 * Left to right from reel 1, which is the rule that makes a slot machine
 * legible: four sevens starting on reel 2 is a near miss and reads as one.
 * Paying it would mean the glass shows a winning line that the player cannot
 * see, which is worse than not paying at all.
 */
export function runOn(
  grid: Symbol[][],
  line: readonly number[],
): { symbol: Symbol; length: number } {
  const first = grid[0]?.[line[0] as number] as Symbol;
  let length = 1;
  for (let reel = 1; reel < line.length; reel += 1) {
    if (grid[reel]?.[line[reel] as number] !== first) {
      break;
    }
    length += 1;
  }
  return { symbol: first, length };
}
```

```ts
const d: Symbol = "dice";

/** Five columns of three. */

describe("the paytable", () => {
  it("pays more for a longer run of the same symbol", () => {

    // Chip three-of-a-kind is 4x the line bet. At a stake of 900 the line bet
    // is 100, so the win is 400 — not 3600.
    const g = grid([c, c, c], [c, c, c], [c, c, c], [d, d, d], [d, d, d]);
    const result = evaluate(g, 900);
    const middle = result.lines.find((line) => line.line === 0);
    expect(middle?.pay).toBe(400);
  });

  it("floors a payout rather than paying a fraction of a chip", () => {
    // Stake 1: the line bet is a ninth of a chip and 4x it is still less than
    // one. Nothing is invented to round it up.
    const g = grid([c, c, c], [c, c, c], [c, c, c], [d, d, d], [d, d, d]);
    expect(evaluate(g, 1).fixed).toBe(0);
  });

  it("adds up every line that wins, not just the best one", () => {
    // All fifteen cells are chips, so all nine lines pay three-of-a-kind at
    // least. A machine that paid only the highest line would be a different
    // and much meaner game.
    const g = grid([c, c, c], [c, c, c], [c, c, c], [d, d, d], [d, d, d]);
    expect(evaluate(g, 900).lines).toHaveLength(9);
    expect(evaluate(g, 900).fixed).toBe(3600);
  });

  it("does not pay for a run of two", () => {
    const g = grid([c, c, c], [c, c, c], [d, d, d], [d, d, d], [b, b, b]);

    expect(evaluate(g, 900).fixed).toBe(0);
```

- [ ] **Step 3: Write the paytable**

`games/slots/src/paytable.ts`:

```ts
import { LINE_COUNT, PAYLINES, runOn } from "./paylines.js";
import type { Symbol } from "./strip.js";

/**
 * What each run is worth, as a multiple of the line bet.
 *
 * Tuned together with the strip weights to land the return at 90%. Neither
 * table means anything without the other, and `rtp.ts` is what keeps them
 * honest — change a number here and that test fails until the pair are back
 * in step.
 *
 * Five sevens is null rather than a large number: the jackpot is a share of
 * the bank, and a multiplier here would be a second way to pay it that could
 * silently disagree with the first.
 */
export const PAYS: Record<Symbol, Record<3 | 4 | 5, number | null>> = {
  chip: { 3: 4, 4: 22, 5: 109 },
  dice: { 3: 7, 4: 33, 5: 164 },
  spade: { 3: 11, 4: 55, 5: 273 },
  horseshoe: { 3: 18, 4: 88, 5: 438 },
  bell: { 3: 33, 4: 164, 5: 875 },
  seven: { 3: 55, 4: 328, 5: null },
};

/** One line that paid, and what it paid. */
export interface WinningLine {
  /** Index into PAYLINES, so the client can light the right one. */
  line: number;
  symbol: Symbol;
  length: number;
  pay: number;
}

/**
 * What a grid is worth at this stake.
 *
 * `fixed` is everything the paytable owes. The jackpot is deliberately not a
 * number here: this file knows nothing about the bank, and a share of the bank
 * is not something a pure function over a grid can work out.
 */
export function evaluate(
  grid: Symbol[][],
  stake: number,
): { lines: WinningLine[]; fixed: number; jackpot: boolean } {
  const lines: WinningLine[] = [];
  let fixed = 0;
  let jackpot = false;

  for (let index = 0; index < LINE_COUNT; index += 1) {
    const line = PAYLINES[index] as readonly number[];
    const { symbol, length } = runOn(grid, line);
    if (length < 3) {
      continue;
    }
    const multiplier = PAYS[symbol][length as 3 | 4 | 5];
    if (multiplier === null) {
      /*
       * The jackpot. A flag rather than a tally: fifteen sevens lights all
       * nine of these, and a jackpot paid once per line is 360% of the bank —
       * the one arrangement in this game that could mint a chip.
       */
      jackpot = true;
      continue;
    }
    // The line bet is a ninth of the stake, floored. Nothing is rounded up:
    // a machine that invents a chip is the thing this whole game avoids.
    const pay = Math.floor((multiplier * stake) / LINE_COUNT);
    fixed += pay;
    lines.push({ line: index, symbol, length, pay });
  }

  return { lines, fixed, jackpot };
}
```

```ts
     * to agree. If lineRtp() ever became a hard-coded number this fails.

      const p = weight / STOPS;

        const multiplier = PAYS[symbol as keyof typeof PAYS][length];

    expect(1 - lineRtp()).toBeCloseTo(0.1, 4);
  });

  it("hits the jackpot about once in fifteen thousand spins", () => {
    expect(Math.round(1 / jackpotOdds())).toBeGreaterThan(14_000);
```

`games/slots/src/rtp.ts`:

```ts
import { LINE_COUNT } from "./paylines.js";
import { PAYS } from "./paytable.js";
import { STOPS, SYMBOLS, WEIGHTS } from "./strip.js";

/**
 * What this machine gives back, worked out rather than measured.
 *
 * A payline reads one symbol per reel, the reels are independent and they
 * share a strip, so the chance of a run of exactly k from the left is a closed
 * form: p^k * (1-p) for k of 3 or 4, and p^5 for a full line. That makes the
 * return a sum of eighteen terms instead of an average over a simulation, so
 * the test that guards it is exact and takes no time at all.
 *
 * The alternative was enumerating all 32^5 grids — 33.5 million of them — on
 * every commit. Five reels made this better, not worse.
 *
 * Per line and per total are the same number, which is worth seeing: nine
 * lines each staking a ninth of the stake returns nine times a ninth.
 */
export function lineRtp(): number {
  let total = 0;
  for (const symbol of SYMBOLS) {
    const p = WEIGHTS[symbol] / STOPS;
    for (const length of [3, 4, 5] as const) {
      const multiplier = PAYS[symbol][length];
      if (multiplier === null) {
        // The jackpot pays from the bank, not from the paytable. It is what
        // the missing tenth below is for.
        continue;
      }
      const chance = length === 5 ? p ** 5 : p ** length * (1 - p);
      total += chance * multiplier;
    }
  }
  return total;
}

/**
 * The return, as a constant, for anything that should not recompute it.
 *
 * Written out so a change to the strip or the paytable fails a test rather
 * than silently moving the number every caller quotes.
 */
export const LINE_RTP = 0.8999724686145782;

/** The chance that a spin lights at least one jackpot line. */
export function jackpotOdds(): number {
  const p = WEIGHTS.seven / STOPS;
  return p ** 5 * LINE_COUNT;
}
```

```ts
import { LINE_COUNT } from "./paylines.js";
import { PAYS } from "./paytable.js";

/** What a jackpot takes out of the bank. */
export const JACKPOT_SHARE = 0.4;

/** The largest fixed win on one line: five bells. */
export const MAX_LINE_PAY = PAYS.bell[5] as number;

/**
 * What the bank has to hold per chip staked.
 *
 * Derived, not chosen. There are two candidate worst spins and the second one
 * binds:
 *
 *   nine top lines          9 * 875 * stake/9  =  875 * stake
 *                           needs bank >= 874 * stake
 *
 *   one jackpot, eight top  0.4*bank + 8*875*stake/9
 *                           0.4*bank + 777.8*stake  <=  bank + stake
 *                                      776.8*stake  <=  0.6 * bank
 *                                             bank  >=  1294.6 * stake
 *
 * Rounded up to 1295, because a cap that is a fraction of a chip too generous
 * is a cap that does not hold. The stake is on the right of both inequalities
 * because it has already entered the bank by the time the reels resolve.
 */
export const STAKE_DIVISOR = 1295;

/**
 * The largest stake this bank can certainly pay out on.
 *
 * A cap rather than a refusal, deliberately. A machine that will not spin
 * until its bank is fat is dark exactly when it is newest, and every quiet
 * week closes it again. A machine that only offers smaller stakes is always
 * playable, and it fills its own bank back up.
 */
export function maxStake(bank: number): number {
  return Math.max(0, Math.floor(bank / STAKE_DIVISOR));
}

/** What a jackpot pays out of this bank. Whole chips, never more than it holds. */
export function jackpotPay(bank: number): number {
  return Math.floor(Math.max(0, bank) * JACKPOT_SHARE);
}

/**
 * The most this bank could possibly owe on one spin at this stake.
 *
 * Both cases, whichever is worse. Exists so the guarantee can be tested as a
 * property over many banks rather than asserted about one.
 */
export function worstCase(bank: number, stake: number): number {
  const topLine = Math.floor((MAX_LINE_PAY * stake) / LINE_COUNT);
  const allFixed = LINE_COUNT * topLine;
  const withJackpot = jackpotPay(bank) + (LINE_COUNT - 1) * topLine;
  return Math.max(allFixed, withJackpot);
}
```

In `apps/server/src/server.ts`, beside the other `socket.on` handlers:

```ts
    /**
     * One pull of the lever.
     *
     * Not a game action, because there is no table: a machine has no seats,
     * no turns and no opponents, and `catalogue.ts` already says that forcing
     * one through a table would bend both out of shape.
     *
     * The order below is the whole safety argument and must not be rearranged:
     * the stake is taken from the player and put in the bank *before* the
     * reels are drawn, so by the time anything is owed the money to pay it is
     * already there.
     */
    socket.on("slots:spin", (payload, ack) => {
      void (async () => {
        const userId = socket.data.identity?.userId ?? null;
        if (userId === null) {
          ack({ ok: false, error: "Sign in to play for chips." });
          return;
        }
        const stake = (payload as { stake?: unknown })?.stake;
        if (typeof stake !== "number" || !Number.isInteger(stake) || stake < 1) {
          ack({ ok: false, error: "That is not a stake." });
          return;
        }

        const bankBefore = await store.bank();
        const cap = maxStake(bankBefore);
        if (stake > cap) {
          ack({
            ok: false,
            error:
              cap < 1
                ? "The bank is empty. Nothing to play for yet."
                : `The bank covers ${cap} a spin at the moment.`,
          });
          return;
        }

        if (!(await deps.take(userId, stake))) {
          ack({ ok: false, error: "Not enough chips." });
          return;
        }
        await store.bankAdd(stake);

        const grid = drawGrid(Math.random);
        const { lines, fixed, jackpot } = evaluate(grid, stake);
        const bankNow = await store.bank();
        const won = fixed + (jackpot ? jackpotPay(bankNow) : 0);

        /*
         * Paid out of the bank, and only if the bank actually has it. The cap
         * above means this cannot refuse; it is checked anyway, because the
         * alternative to checking is a bank that goes negative in silence and
         * a machine that has started minting chips.
         */
        if (won > 0) {
          if (!(await store.bankTake(won))) {
            ack({ ok: false, error: "The bank is short. Nothing was staked." });
            await store.bankAdd(-stake);
            await deps.give(userId, stake);
            return;
          }
          await deps.give(userId, won);
        }

        await deps.record(userId, {
          shared: { games: 1, wins: won > stake ? 1 : 0, chipsWon: won - stake },
          game: "slots",
          add: { spins: 1, staked: stake, jackpots: jackpot ? 1 : 0 },
          max: { bestSpin: won },
        });

        const profile = await store.get(userId);
        ack({
          ok: true,
          grid,
          lines,
          won,
          jackpot,
          bank: await store.bank(),
          balance: profile?.chips ?? 0,
        });
      })();
    });
```
